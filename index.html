Features

Lightning Fast

Edge-deployed on Cloudflare Workers for global low latency.

Encrypted Core

AES-256 encryption with XOR obfuscation support.

Multi-User

Manage multiple users with traffic limits and expiry dates.

Multi-Protocol

VLESS, Trojan, and Clash subscription support.

Quick Setup

1. Create D1 Database

Go to Cloudflare Dashboard → Storage & databases → D1 SQLite Database → Create Database

2. Deploy Worker

Create a new Worker in Compute → Workers & Pages, paste the worker.js code, and deploy.

3. Bind Database

In Worker Settings → Bindings → Add D1 binding with variable name AM_DB

4. Access Panel

Navigate to /panel and login with your password. Default: admin
